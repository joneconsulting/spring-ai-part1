■ 범용 인스턴스 (General Purpose)

- 메모리: 4 GiB
- 네트워크 성능: 최대 5 Gbps

- 권장 용도: 소규모 웹 서버, 개발/테스트 환경, 저트래픽 API 서버

- 권장 용도: 일반 웹 애플리케이션 서버, 중소규모 API 백엔드, CI 빌드 서버

■ 요금 정책

[약정 할인]
- 1년 약정 시 온디맨드 대비 약 30% 할인
- 3년 약정 시 온디맨드 대비 약 50% 할인
- 약정 기간 중 인스턴스 변경은 동일 계열 내에서만 가능

[스팟 인스턴스]
- 온디맨드 대비 최대 70% 저렴
- 사업자가 2분 사전 통보 후 회수할 수 있음
- 중단되어도 무방한 배치 작업, 스테이트리스 워커에만 권장
- 데이터베이스 등 상태를 가진 워크로드에는 권장하지 않음

[스토리지 별도 과금]
- 범용 SSD: 100 GiB당 월 10 USD
- 고성능 SSD: 100 GiB당 월 25 USD
- 스토리지 비용은 인스턴스 요금에 포함되지 않음

■ 선택 가이드

[워크로드별 권장]
- 웹 애플리케이션 서버: 범용 계열(gp) 우선 검토
- 배치·인코딩 등 CPU 집약 작업: 컴퓨팅 최적화(c) 계열
- 캐시·DB·벡터 검색: 메모리 최적화(r) 계열
- 메모리 대비 vCPU 비율이 1:2 이하로 필요하면 컴퓨팅 최적화를 검토
- 메모리 대비 vCPU 비율이 1:8 이상 필요하면 메모리 최적화를 검토

[사이징 원칙]
- 초기에는 필요 사양보다 한 단계 작게 시작하고 모니터링 후 증설하는 것을 권장한다
- CPU 사용률이 지속적으로 70%를 넘으면 상위 인스턴스로 증설을 검토한다
- 메모리 사용률이 지속적으로 80%를 넘으면 메모리 최적화 계열을 검토한다
