# Section 06 — RAG 개념과 Vector Store 기초 (실행 예제)

Section 6은 이론 섹션이지만, **개념을 눈으로 확인하는 3개의 CLI 데모**를 실행합니다.
DB 없이 동작하므로 Docker가 필요 없습니다.

## 준비

```bash
export OPENAI_API_KEY=sk-...
```

> Java 17 이상 필요. Gradle Wrapper가 없으면 `gradle wrapper` 를 먼저 실행하거나
> 로컬에 설치된 `gradle` 명령을 사용하세요.

## 실행

### 데모 ① 임베딩 유사도
```bash
./gradlew bootRun --args='--demo=similarity'
```
"고양이"와 강아지·동물·자동차·주식의 **실제 코사인 유사도**를 출력합니다.
슬라이드의 예시값(0.86 / 0.79 / 0.21)과 비교해 보세요.

```
질의: "고양이"  (임베딩 차원 = 1536)

비교 대상               코사인유사도   막대
----------------------------------------------------------------
강아지                       0.xxxx   ####################
동물                         0.xxxx   ###################
반려묘를 키우는 법            0.xxxx   ###################
자동차                       0.xxxx   ########
주식 투자 전략                0.xxxx   #######
```

### 데모 ② 청킹 비교
```bash
./gradlew bootRun --args='--demo=chunking'
```
같은 문서를 청크 크기 **200 / 500 / 1000** 으로 분할해 개수와 내용 차이를 비교합니다.

### 데모 ③ 미니 RAG
```bash
./gradlew bootRun --args='--demo=minirag'
```
`SimpleVectorStore`(인메모리)만으로 **적재 → 검색 → 생성** 전체 흐름을 실행하고,
**RAG 적용 답변과 미적용 답변을 나란히 출력**합니다.

## 실습 데이터

`src/main/resources/docs/company-policy.txt`
— 강의용으로 **직접 작성한 가상 회사의 인사규정**입니다. 저작권·개인정보 이슈가 없습니다.
실제 법령으로 교체하려면 [국가법령정보센터](https://law.go.kr)에서 내려받아 같은 경로에 두세요.

## 학습 포인트

| 데모 | 확인할 것 |
|---|---|
| similarity | 단어가 달라도 의미가 가까우면 유사도가 높다 / **절대값이 아니라 순위와 격차** |
| chunking | 작은 청크는 문맥 단절, 큰 청크는 노이즈 — 트레이드오프 |
| minirag | 적재·검색·생성 3단계 / **RAG 유무의 답변 차이** |
