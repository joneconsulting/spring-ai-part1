# Spring AI 실전 강의 — 샘플 예제 가이드 (Section 03 ~ Section 15)

이 문서는 각 섹션에서 다루는 샘플 프로젝트의 내용을 소개합니다.
모든 섹션의 `exercise` 폴더 하위에는 **해당 프로젝트를 시작하기 위한 베이스 코드**가 포함되어 있습니다. 수강생은 베이스 코드를 기반으로 강의에서 다루는 기능을 직접 구현하며 실습을 진행합니다.

---

## Section 03. Spring AI ChatClient 기초

Spring AI의 `ChatClient` API를 이용해 LLM과 대화를 주고받는 가장 기본적인 흐름을 학습합니다. 프롬프트 구성 방법, 시스템 메시지 설정, 기본 응답 처리 방식을 다루며 이후 모든 섹션의 토대가 되는 내용입니다.

---

## Section 04. 구조화된 출력 (Structured Output)

ChatClient의 구조화된 출력 기능을 활용하여 LLM의 응답을 Java 객체로 직접 매핑하는 방법을 학습합니다. 샘플 프로젝트 `section04-movie`를 통해 영화 추천 서비스를 예제로 구조화된 출력을 실습합니다.

---

## Section 05. 스트리밍 응답 구현

Server-Sent Events(SSE) 기반의 스트리밍 응답을 구현하여 실시간 채팅형 UX를 완성합니다. `Flux` 기반 비동기 처리와 프론트엔드 연동 방식을 함께 다룹니다.

---

## Section 06. RAG 파이프라인 구축 — 벡터 스토어 연동

벡터 데이터베이스를 Spring AI와 연동하여 문서를 임베딩하고 저장하는 RAG 파이프라인의 첫 단계를 학습합니다. VectorStore 설정과 기본적인 유사도 검색 방법을 다룹니다.

---

## Section 07. 청킹 전략

문서를 효과적으로 분할하는 다양한 청킹(Chunking) 전략을 비교하고 적용합니다. 토큰 기반 분할과 문단 기반 분할 등 전략별 장단점을 실습을 통해 확인합니다.

---

## Section 08. 검색 품질 개선

RAG의 검색 정확도를 높이기 위한 재순위화(Reranking), 하이브리드 검색, 메타데이터 필터링 등의 기법을 학습합니다. 검색 품질을 정량적으로 평가하는 방법도 함께 다룹니다.

---

## Section 09. MCP 개념과 외부 도구 연동 기초

Model Context Protocol(MCP)의 개념을 이해하고, Spring AI 애플리케이션에 첫 번째 MCP 도구를 연동하는 방법을 학습합니다.

---

## Section 10. MCP 심화 — 다중 도구 연동

여러 개의 MCP 도구를 조합하여 복잡한 작업을 처리하는 에이전트형 워크플로우를 구현합니다. 도구 선택 로직과 도구 간 연계 처리 방식을 다룹니다.

---

## Section 11. 멀티모달 입력 처리

이미지 등 텍스트 이외의 입력을 LLM에 전달하고 처리하는 멀티모달 기능을 실습합니다. 이미지 기반 질의응답 서비스 예제를 통해 실전 적용 방법을 익힙니다.

---

## Section 12. Dify 연동

노코드/로우코드 AI 플랫폼인 Dify와 Spring AI 애플리케이션을 연동하는 방법을 학습합니다. Dify 워크플로우 호출과 결과 처리 방식을 다룹니다.

---

## Section 13. 가드레일 적용

프롬프트 인젝션 방지, 출력 검증, 민감 정보 필터링 등 서비스 안정성을 위한 가드레일 구현 방법을 학습합니다. 실제 서비스에 적용 가능한 안전장치 설계 방법을 다룹니다.

---

## Section 14. 부록 — AI 코딩 도구와 Ollama

AI 기반 코딩 보조 도구 활용법과 로컬 LLM 실행 환경인 Ollama 설정 방법을 소개하는 보충 자료입니다. 실습 환경 구성에 참고할 수 있는 내용을 다룹니다.

---

## Section 15. 미니 프로젝트 — 통합 실전 서비스 구현

지금까지 학습한 ChatClient, RAG, MCP, 멀티모달, 가드레일 기능을 통합하여 실제 서비스 형태의 결과물을 완성하는 캡스톤 프로젝트입니다.

---

> 모든 섹션 공통: 각 섹션 폴더 하위의 `exercise/` 디렉터리에는 실습을 시작할 수 있는 베이스 코드가 준비되어 있으며, 수강생은 이를 기반으로 강의에서 안내하는 기능을 단계적으로 구현합니다.
